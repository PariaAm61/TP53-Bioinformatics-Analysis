TP53 Bioinformatics Analysis

A small bioinformatics project focused on basic analysis of the TP53 coding sequence (CDS) using Python and Biopython.

What does this project do?

The script takes a TP53 DNA sequence and performs a few basic sequence analyses:

- Nucleotide composition
- GC content
- Codon analysis
- DNA → protein translation
- Protein sequence length
- Comparison with a reference protein sequence
- Amino acid composition
- Protein molecular weight
- A simple codon mutation example

Tools

- Python
- Biopython

Run the project

First, install the required package:

pip install -r requirements.txt

Then run:

python sequence_analysis.py

The results will be printed in the terminal.

Project Structure

The project contains three main files:

- "README.md" — project description and documentation
- "sequence_analysis.py" — main Python script for the TP53 sequence analysis
- "requirements.txt" — required Python package

Purpose

This project was created to practice basic bioinformatics analysis with Python and Biopython, including working with DNA and protein sequences.
